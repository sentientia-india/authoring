Five-minute MCP quickstart

Connect, verify, and create.

  1. Get your endpoint and key

    Your account provides an HTTPS MCP endpoint and a private license key. Never paste the key into course content.

  2. Add the server

    claude mcp add --transport http samrat-course https://YOUR_DOMAIN/mcp \
  --header "Authorization: Bearer YOUR_LICENSE_KEY"

  3. Verify the connection

    Ask your MCP client: List the Samrat course templates. A successful response returns the available course formats without exposing server details.

  4. Create the first course

    Attach a source and ask: Create a 15-minute course for new managers using this source. Review the proposed outline, approve it, then export SCORM 1.2 or 2004.

Connection should take under five minutes. Course generation time depends on source length, review, and media choices.
